# 🐍 Python DSA

A collection of Python programs demonstrating fundamental **Data Structures and Algorithms (DSA)**. This repository is designed for beginners to learn and practice common algorithms and data structures using Python.

## ✨ Topics Covered

- Arrays
- Linked Lists
- Stack
- Queue
- Binary Tree
- Graph
- Linear Search
- Binary Search
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Recursion
- Dynamic Programming
- Activity Selection
- Fractional Knapsack
- Dijkstra Algorithm
- Matrix Operations

## 🛠 Technologies Used

- Python 3
- Visual Studio Code / PyCharm
- Data Structures & Algorithms
